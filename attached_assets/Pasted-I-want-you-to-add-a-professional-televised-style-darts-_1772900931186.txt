- appear as a red box/panel attached to the side of the existing scoreboard

- hidden state = panel sits behind the side of the scoreboard

- panel should remain mounted if that makes animation smoother

LOGIC REQUIREMENTS

Only show the checkout for the ACTIVE player.

1. detect active player
2. read that player’s remaining score
3. look up that score in a checkout table
4. if a checkout exists, show the panel with the suggested route
