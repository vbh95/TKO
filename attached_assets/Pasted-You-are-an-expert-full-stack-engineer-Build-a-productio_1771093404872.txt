You are an expert full-stack engineer. Build a production-ready web app called “Ultimate Darts Tournament Generator” (UDTG).

GOAL
A darts tournament generator + tournament manager (Score7-style admin) with:
- Tournament formats: Round Robin (groups), Knockout (single elimination), Double Elimination, Multi-Stage (Round Robin → Knockout)
- Per-stage match formats (Best of legs): 3, 5, 7, 9, 11
- Logged-in users have their own tournaments saved permanently (view/edit/delete anytime)
- Public spectator mode via shareable link + QR code (read-only)
- Export tournament data (CSV required, XLSX preferred)
- My Tournaments management page
- My Account page to manage profile/email/password/delete account
- iPad-friendly UI and spectator pages

TECH STACK (use unless impossible)
Frontend:
- React + TypeScript + Vite
- Simple clean admin UI (tabs, tables, forms), responsive, touch-friendly on iPad
Backend:
- Node.js + Express + TypeScript
Database:
- SQLite + Prisma ORM (persist everything)
Auth:
- Email + password with secure hashing (bcrypt or argon2)
- Cookie-based sessions (httpOnly). Use express-session + Prisma-backed session store if feasible, otherwise JWT (but prefer cookie sessions).
Monorepo:
- Replit-friendly single workspace with frontend + backend.
- Provide one command to run everything: “npm run dev” (use concurrently).

NON-NEGOTIABLES
- All data persists in SQLite; refresh must not lose data.
- Ownership enforced: users can only access their own tournaments and exports.
- Public spectator links must be read-only and must not reveal any private account info.
- Include README with setup/run instructions and rules.

4A) MATCH FORMATS (PER STAGE) — BEST OF LEGS
Allowed best-of values: 3, 5, 7, 9, 11
Store match.bestOf at match creation time.

Group stage:
- Group stage Best-of selector (applies to all group matches)

Knockout stage (single elim + multi-stage knockout):
- Per-round best-of selectors shown dynamically based on bracket size:
  - e.g., R32, R16, Quarter Finals, Semi Finals, Final
- Always include Final
- If third place playoff is enabled: “Third Place Final best-of” selector
- EXPLICIT REQUIREMENT: provide selectors for QF/SF/Final when applicable:
  - Quarter Final best-of: 3/5/7/9/11
  - Semi Final best-of: 3/5/7/9/11
  - Final best-of: 3/5/7/9/11

Double Elimination:
- Per-round best-of selectors for Winners Bracket and Losers Bracket (dynamic)
- Grand Final best-of selector always shown
- Optional: “Grand final reset” toggle (if implemented). If not implemented, document clearly.

Score validation:
- legsToWin = (bestOf + 1) / 2
- On score entry, enforce:
  - winner must reach legsToWin
  - loser must be < legsToWin
  - total legs <= bestOf
- Show friendly inline errors. Do not allow invalid saves (unless you implement an admin override toggle—optional).
