I want to add a televised-style “Winner” end-of-match state to my existing darts stream overlay.

CONTEXT

My overlay already shows:
- match format
- player names
- sets
- legs
- remaining score
- active player indicator
- suggested checkout panel

The overlay is used in OBS as a browser source and updates live from my scoring system.

NEW REQUIREMENT

When a match is completed, I want the normal live scoreboard overlay to transition into a clean winner graphic.

At the completion of a match, the overlay should animate into a box that says:

Winner
[Player Name]

This winner graphic should remain on screen until the NEXT match has been started from the tablet scoring system.

GOAL

Build a winner-state overlay that:
- automatically appears when the current match is marked complete
- shows the winner’s name clearly
- replaces or transforms from the normal scoreboard overlay
- stays visible after the match ends
- remains visible until the next match actually starts
- disappears only when a new live match begins from tablet scoring

The winner state should look professional and broadcast quality, like a televised darts event graphic.

- a main title: “Winner”

Use the match state already available in the app.

2. MATCH COMPLETE / WINNER STATE

- show the winner graphic

3. NEXT MATCH STARTED

- if current match is completed and no new match is active yet → keep showing winner
