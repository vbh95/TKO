I want to enhance the LIVE match display in both:
1. the admin panel live matches view
2. the public live matches page

NEW BEHAVIOUR REQUIRED
When a leg is completed, the live display for that match should temporarily show:
- the name of the player who won the leg
- the checkout value
- the number of darts used on the checkout

This temporary leg-win display should remain visible until:
- the next score is entered from the tablet scorer for that same match
OR
- the next game/match begins on that board/tablet

After that, the live display should return to the normal live match view/state automatically.

EXAMPLES
If Hallam wins a leg by taking out 72 in 2 darts, the live display should show something like:
- Leg won: Hallam
- Checkout: 72
- Darts used: 2

or a compact equivalent such as:
- Hallam won leg
- CO 72 (2 darts)

IMPORTANT SCOPE
- This is for the live display only
- It must appear in both the admin live view and the public live page
- It should be tied to the current live match/board state
- It should not overwrite historical match stats
- It should not permanently replace the normal live score display
- It should only persist until the next score is input or the next game starts
